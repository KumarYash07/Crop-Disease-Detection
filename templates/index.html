System Pipeline

How the Detection Pipeline Operates

A modular deep learning inference pipeline designed for real-time agricultural visual screening.

1
Image Acquisition

Foliar photograph upload with automatic MIME type verification, size limit checks, and EXIF orientation normalization.

2
Preprocessing

Resizing to 224×224 pixels and scaling channel values to [-1, 1] matching MobileNetV2 training specifications.

3
CNN Inference

Deep spatial feature maps generated via inverted residual bottleneck layers with softmax probability extraction.

4
Agronomic Advisory

Dynamic lookup against structured agricultural knowledge base providing symptoms, prevention, and management guidance.

Dataset Scope & Deployment Limitations

PlantVillage is an open-access dataset curated primarily under controlled lighting conditions with uniform backgrounds. Real agricultural applications face challenges such as varying natural sunlight, leaf motion, overlapping foliage, and soil background clutter. Academic evaluations must report held-out test splits without claiming absolute generalizability to unrestricted in-field photographs.
