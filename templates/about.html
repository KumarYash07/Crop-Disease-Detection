Technical Documentation & Methodology

Crop Disease Detection using CNN

B.Tech Computer Science and Engineering Capstone Project. An academic examination of Convolutional Neural Networks, Transfer Learning with MobileNetV2, and automated plant leaf pathology screening.

1. Problem Statement & Motivation

Plant diseases and foliar pathogens represent a significant threat to global food security, responsible for an estimated 20% to 40% loss of worldwide crop yields annually. In conventional farming, disease identification relies heavily on manual visual inspection by agricultural extension officers or laboratory biological assays. However, expert access is often scarce, costly, and geographically constrained in rural communities.

This project investigates the application of deep Convolutional Neural Networks (CNNs) to automate foliar disease classification from RGB digital photographs. By combining deep feature extraction with structured agronomic knowledge, the system delivers instantaneous diagnostic screening and verified management recommendations.

2. CNN Architecture & Transfer Learning

Rather than training an arbitrary deep network from scratch with random weight initializations, this project employs Transfer Learning utilizing the MobileNetV2 architecture pretrained on the ImageNet dataset (1.4 million images across 1,000 object categories).

Why MobileNetV2 for Crop Pathology?
  • Depthwise Separable Convolutions: Factorizes standard 3D convolutions into a depthwise spatial filter and a 1×1 pointwise projection, reducing computational complexity (FLOPs) by ~8× with minimal accuracy loss.
  • Inverted Residuals with Linear Bottlenecks: Retains non-linear feature representations in low-dimensional bottleneck layers without destroying critical gradient flows, allowing deep feature propagation.
  • Edge & Mobile Friendly: With ~3.5 million parameters, MobileNetV2 is lightweight enough to run in real-time on resource-constrained devices, edge computers, and low-cost farm smartphones.
Custom Classification Head:
  1. Input Layer: Accepts 224 × 224 × 3 tensors normalized to the range [-1.0, 1.0].
  2. Base Feature Extractor: MobileNetV2 frozen base extracting rich multi-scale spatial textures.
  3. Global Average Pooling (GAP): Collapses 7 × 7 spatial feature maps into a 1D vector (1,280 features), dramatically reducing parameters compared to traditional dense flatten layers.
  4. Batch Normalization: Accelerates convergence and stabilizes internal covariate shift.
  5. Fully-Connected Dense Layer: 256 units with Rectified Linear Unit (ReLU) activation.
  6. Dropout (0.4): Stochastically deactivates 40% of neurons during training to prevent co-adaptation and penalize overfitting.
  7. Output Layer: Softmax activation over target disease classes, outputting a valid probability distribution where ∑ pi = 1.0.

3. Deep Learning Concepts (Viva Reference)

A convolutional layer applies learnable sliding filters (e.g. 3×3 matrices) across the input image. Each filter computes dot products with local receptive fields, generating feature maps that capture spatial hierarchies: early layers capture low-level edges and color gradients, while deeper layers detect complex biological textures like concentric rings, pustules, and vein lesions.

Sigmoid activates each output neuron independently between 0 and 1 (ideal for binary or multi-label classification). For mutually exclusive single-class multiclass problems (e.g., choosing 1 of 38 categories for a single leaf), Softmax normalizes raw logits across the entire class spectrum using the exponential function: P(y=i) = exp(z_i) / ∑ exp(z_j), enforcing that all probabilities sum strictly to 1.0.

Overfitting occurs when a model memorizes idiosyncrasies of training samples rather than generalizing to unseen data. Early Stopping monitors validation loss (val_loss) at each epoch. If validation loss ceases to improve for a predefined patience period (e.g. 5 epochs), training halts automatically and weights from the best performing checkpoint are restored.

4. Dataset & Scientific Limitations

The model is trained on the benchmark PlantVillage dataset (Hughes & Salathé, 2015). While PlantVillage provides standardized labels and high-resolution foliar captures, academic rigor requires acknowledging critical environmental constraints:

  • Controlled Lab Conditions: PlantVillage leaves were detached and photographed against uniform gray or black backdrops under controlled diffuse illumination.
  • Context & Background Bias: In actual agricultural fields, cameras encounter complex natural clutter: soil, sunlight glares, morning dew, shadows, overlapping leaves, and background weeds.
  • Dual Infection: Plant leaves can suffer from concurrent nutrient deficiencies (e.g., nitrogen chlorosis) and viral infections simultaneously, which single-label classification cannot fully decompose.

5. Future Scope & Roadmap

Edge AI & TFLite

Quantizing the Keras model to 8-bit integer TensorFlow Lite (TFLite) for offline on-device deployment in rural mobile apps without internet connectivity.

Semantic Segmentation

Integrating YOLOv8 or U-Net to segment necrotic lesions and quantify leaf disease severity percentage rather than whole-image classification.
